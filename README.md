# Liseuse

La [liseuse](https://fxpar.github.io/Wang_Fuzhi-Zhouyi_Neizhuan/liseuse.html) lit directement le texte homogène de `français/markdown/`. Elle permet d'afficher ou de masquer le chinois original, le pinyin intégral et la traduction ; dans la traduction, les symboles (hexagrammes, trigrammes), les caractères, le pinyin et les gloses de chaque terme ; de les surligner ; de n'afficher que le texte classique. Les passages traduits deux fois (reprises après un blocage des outils d'IA) sont repliés dans un accordéon.

Les anciens liens `liseuse.html?post=…/html-balises/1atag.html` restent valides : ils ouvrent le chapitre correspondant. Le lien court est `liseuse.html?ch=1a`.

# Format du texte

Depuis novembre 2026, les traductions de `français/markdown/` suivent une syntaxe unique, décrite dans [outils/SYNTAXE.md](outils/SYNTAXE.md) : passages `::: jing` / `::: comm` / `::: note` avec des lignes `zh:` `py:` `fr:`, et termes balisés `{zh:孚 | py:fú}`. Ils sont générés à partir des textes d'origine par `sh outils/tout_convertir.sh` ; les contrôles et cas à vérifier sont dans `outils/rapports/`.

# Archives

`_archives/` conserve les versions précédentes : les textes Markdown d'origine (`markdown-v1/`, source de la conversion) et l'[ancienne liseuse](https://fxpar.github.io/Wang_Fuzhi-Zhouyi_Neizhuan/_archives/liseuse-v1.html). Les pages `français/html-simple/` et `français/html-balises/` restent en place pour les liens existants, mais ne sont plus mises à jour.

# Artefact

L'outil [Artefact-md-semantic.html](Artefact-md-semantic.html) permet de créer des règles pour isoler les parties du texte markdown et insérer des balises sémantiques et de mise en forme en html. Les expressions régulières (rationnelles) de recherche et remplacement ont été créées par IA.
